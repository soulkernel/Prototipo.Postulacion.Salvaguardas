VERSIONADO Y CONSERVACIÓN
Se introduce currentAlignmentVersion = pg2030-ods-general-v3 para las nuevas versiones
del formulario. alignmentVersion conserva su valor v2 para leer fielmente las versiones
anteriores; también se mantiene el formato legacy v1.

La nueva generación de objetivos v3 no crea el campo contribution y el esquema permite
que esté ausente. Si ya existe, admite su texto histórico (con los límites anteriores)
y lo conserva como dato inactivo. No se copia a objetivos, resultados, beneficiarios,
resumen ni otra narrativa. Los UUID de objetivos y sus relaciones no cambian.

Al editar un borrador anterior, el editor lo adapta en memoria al formato v3 para que
el campo retirado no siga siendo obligatorio. El guardado existente puede persistir
esta nueva versión del borrador; el texto original de contribution se conserva.
No se borran tampoco las contribuciones de objetivos específicos de formatos antiguos.
Los expedientes no editables no se convierten, y las versiones enviadas o documentos
preparados conservan el payload y la versión originales.
